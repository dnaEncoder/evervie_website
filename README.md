# Evervie React Router Wireframe App

A Vite + React Router wireframe prototype with three homepage layout variations and working navbar dropdowns.

## Run locally
npm install
npm run dev

## Deploy on Vercel
Framework preset: Vite
Build command: npm run build
Output directory: dist

## Routes
/ - comparison page
/editorial - Editorial layered scroll
/bento - Modular bento layout
/journey - Journey and hub layout
